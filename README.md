# 学習時間記録

教科別の学習時間を記録し、今日・今週・今月の合計、連続学習日数、教科別内訳を確認する静的Webアプリです。

## 主な機能
- 日付・教科・学習時間・メモの記録
- 記録の編集・削除
- 今日・今週・今月の合計
- 1日の目標と達成率
- 連続学習日数
- 教科別集計
- 履歴検索と教科絞り込み
- JSONバックアップとCSV書き出し
- 既存タイマーへのリンク
- PC、タブレット、スマートフォン対応

## タイマーとの連携
最小完成版では、タイマー終了後の時間を手動で入力します。将来はタイマー側に「学習記録へ追加」を実装する予定です。

## 公開方法
1. GitHubで `study-time-tracker` というPublicリポジトリを作成します。
2. 4ファイルをアップロードします。
3. Settings → Pagesでmainブランチのrootを公開します。
